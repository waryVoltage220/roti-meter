### Project Description
[2-3 lines about what your project does]

Roti-Meter 3000 Ultra is an AI-powered Euclidean audit platform that inspects chapatis for circularity, maternal approval, and accidental continental drift. It features real-time camera scanning, spoken maternal roasts, and an emergency flying-chappal protocol for non-round flatbreads—with an automatic 100% bypass for the superior Malabar Porotta.

### The Problem (that doesn't exist)
[What ridiculous problem are you solving?]
Millions of households suffer daily from non-Euclidean flatbreads. Asymmetrical chapatis lead to disastrously uneven ghee dispersion, severe structural curry failure, and unquantifiable maternal disappointment. Until now, there has been no defense-grade system to verify whether dough qualifies as a sovereign geometric sphere or an accidental tectonic plate.

### The Solution (that nobody asked for)
[How are you solving it? Keep it fun!]

Roti-Meter 3000 Ultra: A browser-native, camera-enabled flatbread audit terminal. It measures circularity using proprietary geodesic algorithms, identifies accidental continental outlines (e.g., Australia vs. South America), calculates Matrimonial Viability, and issues real-time maternal roasts via browser voice synthesis. In critical failure scenarios (<70% roundness), the system triggers an emergency Flying Chappal alert—while offering a 100% automatic bypass for the inherently superior Malabar Porotta.
